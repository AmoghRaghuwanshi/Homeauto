# HomeAuto — implemented security and release gates

Revision 4, 2026-11-05. Threat-model history is preserved in history/revision-3/SECURITY.md. The active runtime uses the controls below; unverified deployment/hardware cases remain open. See RUNTIME_CONTRACTS.md and OPERATIONS.md.

| Boundary | Implemented protection | Evidence / limit |
|---|---|---|
| Household HTTP data | Auth required for reads and mutations; same-origin only; Host allowlist; JSON 16KiB; strict fields and limits; sanitized error envelope; no-store | HTTP/Host/Origin/body tests. No internet/public binding by default. |
| Identity | Console-only provisioning, no default password, async scrypt N32768/r8/p1; bounded concurrent hashes; per-account/IP throttles | Token hash/expiry/reauth tests. OS account/volume permissions remain operator work. |
| Sessions | Random 32-byte cookie token, SHA256 stored; HttpOnly/SameSiteStrict; Secure __Host cookie over TLS; idle30m/absolute8h; password reauth5m rotates token; logout/restart revoke | Real temporary HTTPS test verifies trusted handshake and Secure cookie. No household trust installed. |
| Mutations | Exact Origin + CSRF header + JSON; 90/user/min writes; metadata versions and idempotency | HTTP authorization/CSRF/schema/duplicate tests. TLS required for LAN binding. |
| Realtime | One dispatcher, Origin/session checks for both paths, periodic session expiry, revoke/disconnect handling, caps/ping/backpressure | Authorized and forbidden /ws,/voice upgrades tested; control messages never decoded as PCM. |
| Command execution | Fixed hardware registry, allowlisted actions, shared service, durable request before publish, pending lock, deadlines, no optimistic state or offline replay | Fake publisher/report/timeout/restart/retained/idempotency tests. Reports are temporally correlated and physical_verified is always false. |
| Door/RFID | Gate off by default; owner-only RFID CRUD + fresh password; canonical UID and version; manual unlock additionally needs can_unlock and single-use session challenge; voice/text unlock refused | Automated policy and reauthentication tests cover duplicate grants, revocation and cancellation. Cloneable UIDs and no contact/bolt feedback remain physical limits. |
| MQTT | Credentials required, TLS for remote broker, exact topics, QoS0/retainfalse/clean/noofflinequeue | Plain remote URL rejected before connect; adapter policy tested with fake publisher. Broker ACL templates unverified against real Mosquitto; legacy sketches need secure credentials/transport. |
| Browser rendering | Safe node/text creation; CSP self scripts/styles/connect, no inline handlers; no external asset/font; original local SVGs; bounded plain-text metadata | Malicious RFID label displayed literally; automated CSP/browser checks pass. Old frontend scripts are not loaded. |
| Storage | Prepared SQL, atomic temp/fsync/backup/rename, single-writer lock, memory rollback on export failure, blocked writes on disk error, backups/retention/checksummed restore | Windows temp-copy migration and simulated disk-full tests pass; actual power interruption remains unverified. |
| Speech privacy | Tap only; bounded capture; tickets; isolated workers without broker secrets; no raw runtime audio/transcript file or global transcript broadcast; owned no-store TTS jobs expire60s | Native synthetic-stream integration passes; actual Windows fake-file mic API failed NotSupportedError. Real permission/phone tests remain open. |
| Models | Fixed profile IDs, pinned hashes checked before native loading; no arbitrary upload/download/path/shell API | Actual SHA256 checks/native probes executed. Initial Vosk manifest records existing baseline, not an upstream signature. Redistribution licensing remains pending. |

The original bundled certificate/key is treated as exposed. It is preserved in the private baseline for recovery, ignored by source control and never read by the active runtime. Both certificate-generation CLI paths now write only to .local/tls, refuse overwrite and use fresh 90-day leaf certificates. Revoke/remove the old trust and any published history before deployment. No private key content was logged or copied into docs.

Production DB and original firmware/cert/reference files remain unchanged. Tests use in-memory or temporary fixtures, and no production broker was contacted. The original anonymous/blocking firmware must not be deployed by weakening broker policy. Keep HOMEAUTO_DOOR_ENABLED=0 until supervised relock/network/power/fail-mode/egress checks pass. Browser gas readings are uncalibrated and cannot replace an independent alarm.

No security release signoff is implied by zero npm advisories or simulator passes. Actual ACL enforcement, household TLS trust/firewall/service account, hardware fail modes, assistive technology and microphone privacy behavior require operator validation. No push, flash, public listener, trust-store install or service registration occurred.
