## Visual recommendations kept subordinate to the product

- If simplifying labels, change desktop Controls and the sample Preview treatment within the existing design; do not replace functional “unlock,” sensor qualifiers or Hindi text because of a generic copy scanner.
- Treat the 64 spacing records as one component-system task. Do not bulk-round every numeric dimension; outlines, hit areas, swatches and alignment may have optical or accessibility reasons.
- Do not add overflow clipping just to silence gate 34. First demonstrate reflow under long names, Hindi, zoom and dialogs; ensure any later clipping cannot hide focus or content.
- The reported 4.43:1 bulb-icon contrast is above its 3:1 threshold. Do not change a theme on this evidence.
- Keep familiar icon wells, native dialogs and larger controls where they help the audience. Do not impose marketing photography, heroes, compact 32px controls or Hallmark catalog themes.
- A static “JavaScript is required / reload or check the local hub” fallback could improve resilience. It must not display invented hardware state and is optional, not a newly counted defect.

## Cross-cutting regression contract

Maintain MQTT topics/payloads and immutable device IDs/pins. Keep authentication, CSRF, role/grant, reauthentication and single-use unlock confirmation. Do not convert a controller relay report into physical-lock proof. Acknowledging/reading an alert must not resolve danger. Keep microphone off until an explicit user gesture; preserve local-only capture, result ownership and no cloud fallback. Never replay uncertain actions after reconnect.

Persistence changes must distinguish browser preferences, shared metadata and authoritative observations. Do not use localStorage as hardware truth. UI repairs should keep the one router, parent fallback, native history, language/theme bootstrap and security-sensitive draft clearing.

Acceptance is evidence-based: a build or axe pass alone does not close these findings. For each issue record reproduced-before, implemented change, isolated regression result, residual hardware/manual limitation and final source diff.
