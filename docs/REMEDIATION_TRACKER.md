## Implementation decisions and limits

Parser consumes complete supported target/action grammar and rejects unknown qualifiers, future/conditional requests and unsupported mixed targets. It is intentionally bounded, not a universal language promise. Session reads never touch idle time; trusted pointer/keyboard activity sends a throttled CSRF-protected activity request. Reauth retains original absolute session bound. Timer faults fail closed.

Room backfill runs only for migration before schema5. Telemetry and metadata versions are separate. UI keeps stable focus IDs/disclosure state, shows effective unavailable state on disconnect/age, provides alert-detail entry/read counts and visible async errors, and retains date recovery controls. Startup classifies401 separately from service errors; async views show frame/loading before data with existing generation guards.

Speech replay requeries current observations for queries; command history says Earlier controller report with recorded time. Group result IDs preserve per-target failure speech, and Auto follows resolved result language. Readiness changes never start capture. Local Vosk/Kokoro and MQTT contracts are preserved.

Restore rejects future versions, trial-opens/migrates a disposable copy and compares required schema columns before replacing target. Supported backup/checksum/lock tests pass. Real OS interruption, power loss and exclusive operator restore procedure still need external validation.

No firmware edit/flash, real MQTT connection/relay/door/RFID operation, certificate rotation, live DB write or household service restart. Protected firmware/cert/original DB/deploy/lockfile hashes match baseline. All test services were ephemeral simulators or memory/temp fixtures.

Manual phone/notch/native zoom/NVDA, older-user and native-language/consented speech quality remain open release gates. Software tests do not certify physical bolt state, calibrated gas or safe egress.
