# Firmware source for the current two-board build

The light-controller sketch now adapts the user's [VidyutRakshak hardware repository](https://github.com/Mishrajishri/home-security-simple/tree/480b51b1d73cbc86ae65b044bc64562ca23386c4/firmware), preserving its relay GPIOs and NVS state recovery. It covers three lights, the fan, gas and optional motion. PIR reporting is disabled for the current installation because no motion sensor is connected.

Use the light sketch with the secure HomeAuto broker. It requires a private `homeauto_config.h` generated by `scripts/setup-hardware.js`, using `board: "lights"` in the private provisioning input. See [commissioning](../docs/verification/HARDWARE_COMMISSIONING.md). It uses CA-validated TLS MQTT and board credentials. The door sketch remains unchanged as requested; it is an older reference and is not part of this commissioning. No sketch has been flashed or physically tested during this review.
